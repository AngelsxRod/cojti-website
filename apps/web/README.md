# Sitio web de Demetrio Cojtí Cuxil

Aplicación Next.js del sitio personal. Desde la raíz del repositorio, ejecute `pnpm dev` y visite `http://localhost:3001`.

La página obtiene los enlaces desde `API_URL` o, de forma predeterminada, desde `http://localhost:3000`. Si la API no está disponible, el resto de la página sigue funcionando.
